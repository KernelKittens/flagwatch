Accessibility

Our target

Flagwatch targets WCAG 2.2 Level AA. The calendar is tested with keyboard navigation, screen readers, zoom, reduced motion, high contrast, and automated browser checks.

Report a problem

If something blocks you, email accessibility@kitsunetechnologies.org. Include the page address and what you were trying to do if you can. We aim to acknowledge accessibility reports within 48 hours.

Known gaps

We do not currently know of a critical accessibility blocker. Automated checks cannot catch every problem, so direct reports still matter.

Text access

The calendar data is also available through a read-only public API. The full event schedule can be read without using the visual calendar.
